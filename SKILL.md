# Hollywood

Inspect studio_media_capabilities before choosing an operation. Select the user's
existing project, reuse assets, submit supported jobs, poll to completion and inspect
actual media. Queued is not finished; technical execution is not artistic approval.

Use render_scene for procedural visuals, compose_program for ordered sequences,
and the get/configure/control_scene_channel tools for private live preview. Live
chunks use 8/16/24 seconds, default 16. Use prepared broadcast programs for supported
external destinations; do not claim the rolling preview is externally broadcast.

Preserve originals, bound scratch storage, and retain explicit start/stop intent.
Start an external channel only when the user supplies a destination and instruction.
Do not promise unavailable models, seamless filler audio, real-time 4K or
photorealistic scenery. Read README.md and public third-party notices.
